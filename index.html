01 — Account Types

Storage Account Types

🏦 General Purpose v2

Standard GPv2

The recommended account type for most scenarios. Supports Blob, File, Queue, Table, and Data Lake Storage Gen2. Supports all redundancy options and access tiers.

⚡ Premium

Premium Block Blobs

High-performance storage for block blob and append blob workloads requiring low-latency. Ideal for AI/ML, analytics, and interactive workloads with high transaction rates.

📁 Premium

Premium File Shares

SSD-backed file shares for enterprise or high-performance applications. Supports both SMB and NFS protocols. Use for HPC, databases, and latency-sensitive workloads.

💾 Premium

Premium Page Blobs

Optimised for random read/write operations. Primarily used for Azure Virtual Machine OS and data disks, Oracle databases, and other I/O-intensive workloads.

🗄️ Legacy

Standard GPv1

Older general-purpose account — supports all storage services but lacks access tiering and some newer features. Microsoft recommends upgrading to GPv2 for most use cases.

📦 Legacy

Blob Storage (Legacy)

Supports only block blobs and append blobs. Introduced access tiers (Hot/Cool/Archive). Largely superseded by Standard GPv2 which offers the same capabilities and more.

03 — Services

Storage Service Types

01

Azure Blob Storage

Object Storage · REST API

Massively scalable object store for unstructured data — documents, images, videos, logs, and backups.

  • Block Blobs — large file uploads
  • Append Blobs — log data, telemetry
  • Page Blobs — random read/write (VHDs)
  • Data Lake Storage Gen2 (hierarchical namespace)
02

Azure Files

Managed File Shares · SMB / NFS

Fully managed cloud file shares accessible via SMB 3.x and NFS 4.1 protocols — lift-and-shift of on-premises file servers.

  • Azure File Sync (hybrid caching)
  • Identity-based access (AD, AAD DS)
  • Snapshots for point-in-time recovery
03

Azure Queue Storage

Message Queue · Async Decoupling

Simple, reliable message queueing for asynchronous communication between application components at scale.

  • Up to 64 KB per message
  • Millions of messages per queue
  • TTL, visibility timeout support
04

Azure Table Storage

NoSQL · Key-Value Store

Schemaless NoSQL key-value store ideal for structured, non-relational data at low cost. Part of Cosmos DB Table API ecosystem.

  • Fast queries via partition + row keys
  • Auto-scaling throughput
  • Fully compatible with Cosmos DB Table API
05

Azure Disk Storage

Managed Disks · VM Block Storage

Block-level storage volumes used with Azure Virtual Machines. Managed and unmanaged disk options available.

  • Ultra Disk — sub-ms latency
  • Premium SSD v2 — production workloads
  • Standard HDD — dev/test, backups
06

Azure Data Lake Gen2

Analytics · Hierarchical Namespace

Built on Blob Storage with a hierarchical namespace enabled. Optimised for enterprise big data analytics using Hadoop-compatible APIs.

  • POSIX-like ACLs
  • Works with Databricks, Synapse, HDInsight
  • ABFS driver for Hadoop workloads
04 — Access Tiers

Blob Access Tiers

🔥

Hot

Frequently accessed data. Highest storage cost, lowest access cost.

High storage · Low access
❄️

Cool

Infrequently accessed data stored for at least 30 days.

Lower storage · Higher access
🧊

Cold

Rarely accessed data, minimum retention of 90 days. Introduced 2023.

Low storage · High access
🗃️

Archive

Offline tier for data stored ≥180 days. Rehydration required to access (hours).

Lowest storage · Highest access
05 — Security & Management

Security & Key Features

🔐 Encryption

Storage Service Encryption

All data is encrypted at rest using AES-256 by default. Supports Microsoft-managed keys (MMK), customer-managed keys (CMK) via Azure Key Vault, and customer-provided keys.

🌐 Network

Network Security

Restrict access using service endpoints, private endpoints (Private Link), IP firewall rules, and virtual network rules. Supports trusted Microsoft services bypass.

🪪 Identity

Azure AD & RBAC

Role-Based Access Control via Azure Active Directory for fine-grained permissions. Built-in roles include Storage Blob Data Owner, Contributor, and Reader.

🔑 Delegation

Shared Access Signatures

Grant time-limited, scoped access to storage resources without exposing account keys. Supports Service SAS, Account SAS, and User Delegation SAS (recommended).

🛡️ Protection

Data Protection

Soft delete for blobs, containers, and file shares. Blob versioning, point-in-time restore, and immutable storage (WORM) for compliance-regulated workloads.

📊 Monitoring

Monitoring & Diagnostics

Azure Monitor metrics, diagnostic logs via Log Analytics, Storage Analytics, and Microsoft Defender for Storage for threat detection and anomaly alerts.
